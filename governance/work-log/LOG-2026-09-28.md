# LOG-2026-09-28.md — UdiFy (plain-English daily log)

## What we set out to do

You asked to clean up the project so it only contains the live, working
code — and specifically to get rid of "mock mode," which was creating
confusion. You want to work directly against the real government portals
from here on and build things up step by step by actually looking at the
real page each portal shows, instead of relying on the fake practice pages
the app used to test against.

## What I did

Before deleting anything, I checked how deep "mock mode" actually went —
it turned out to touch 20 different code files and roughly half the
automated test suite, not just a couple of leftover files. I explained
that tradeoff to you (removing it means losing the fast, safe way of
testing the app without touching the real portals) and you confirmed you
wanted the full removal anyway.

Then I:
- Deleted the fake practice pages (the local HTML files standing in for
  the Gujarat and National government portals) and the ~17 test files that
  only existed to test against those fake pages.
- Removed the "MOCK vs LIVE" switch from the app entirely — the app now
  only ever knows how to run for real. There's no more setting that could
  accidentally leave it running against fake data.
- Cleaned up the screens, messages, and code comments that referred to
  "MOCK sample data" or a demo mode, since that no longer exists — the app
  now always shows and works with the school's real student list.
- Kept one small, unrelated thing: a lightweight practice stand-in for the
  Google Sheets connection (not the government portals) that some tests
  still use internally, purely to test business logic quickly. This isn't
  used by the actual app when you run it — only by test code — so it isn't
  part of the "mock mode" confusion you were pointing at. I flagged this
  choice for you in the technical notes in case you'd rather I remove that
  too.
- Ran the full test suite repeatedly while making changes to make sure
  nothing broke. Final result: 191 out of 191 tests pass.

## Decisions

- You chose full removal of mock mode over the more conservative option
  (keeping the fake pages only for internal testing, hidden from the app).
- I made one judgment call on your behalf without asking again: keeping
  the small Google-Sheets test stand-in described above, since it's a
  different thing from the portal mock-mode you were annoyed by.
